Про проєкт

Каталог фільмів та серіалів — навчальний проєкт для вивчення HTML5.

Етапи розробки та використані технології

Як створювався цей сайт

  1. Створення базової структури index.html.
  2. Налаштування глобальної навігації для зв'язку між файлами.
  3. Розробка сторінки details.html із застосуванням таблиць та <picture>.
  4. Верстка сторінки about.html із відео та FAQ.
  5. Валідація коду через W3C Nu HTML Checker.

Що з'явиться в наступних роботах

  • Оформлення сторінок за допомогою CSS
  • Робочі фільтри та пошук на JavaScript
  • Динамічне наповнення сторінки деталей
  • Додавання фільмів до списку «переглянуті»

Відеопрезентація проєкту

Нижче представлено коротке відео (трейлер) для демонстрації роботи тегу відео в HTML5.

Часті запитання (FAQ)

Чому цей сайт виглядає так просто, без кольорів?

Мета цієї лабораторної роботи — вивчення саме структури та семантики HTML-документа.

Для чого потрібні елементи details та summary?

Вони дозволяють створювати інтерактивні розкривні блоки виключно засобами HTML, без використання JavaScript. Це корисно для приховування великих обсягів тексту.

Що таке "семантична розмітка"?

Це використання HTML-тегів за їхнім прямим призначенням (наприклад, <article> для незалежного контенту, а не просто <div>). Це робить сайт зрозумілим для пошукових систем та людей із вадами зору.
