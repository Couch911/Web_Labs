Етапи розробки та використані технології

Як створювався цей сайт

  1. Створення базової структури index.html.
  2. Налаштування глобальної навігації для зв'язку між файлами.
  3. Розробка сторінки details.html із застосуванням таблиць та <picture>.
  4. Верстка сторінки about.html із відео та FAQ.
  5. Валідація коду через W3C Nu HTML Checker.

Використані теги та технології (Маркований список)

  • Семантичні теги: <header>, <main>, <nav>, <footer>
  • Машинно-читані дані: <time>, <data>
  • Медіа: <video>, <picture>
  • Інтерактивні елементи: <details>, <summary>

Часті запитання (FAQ)

Чому цей сайт виглядає так просто, без кольорів?

Мета цієї лабораторної роботи це вивчення саме структури та семантики HTML-документа. Оформлення (кольори, шрифти, сітки) буде додано пізніше за допомогою каскадних таблиць стилів (CSS).

Для чого потрібні елементи details та summary?

Вони дозволяють створювати інтерактивні розкривні блоки виключно засобами HTML, без використання JavaScript. Це корисно для приховування великих обсягів тексту, як-от відповідей на часті запитання.

Що таке "семантична розмітка"?

Це використання HTML-тегів за їхнім прямим призначенням наприклад, <article> для незалежного контенту, а не просто <div>). Це робить сайт зрозумілим для пошукових систем (SEO) та людей із вадами зору, які використовують скрінрідери.
